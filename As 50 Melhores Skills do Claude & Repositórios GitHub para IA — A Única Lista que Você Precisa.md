## Meus Servidores MCP Indispensáveis

Além das skills — eu adoro usar estes. As skills ensinam o Claude COMO fazer as coisas. O MCP dá a ele ACESSO ao mundo exterior. Estes três mudaram meu fluxo de trabalho.

### Tavily
Motor de busca construído para agentes de IA. Não são links azuis — dados estruturados limpos. Quatro ferramentas: busca, extração, rastreamento (crawl), mapeamento. Conecta-se como MCP remoto em um minuto.
[https://github.com/tavily-ai/tavily-mcp]

### Context7
Injeta documentações de bibliotecas atualizadas no contexto do seu LLM. Chega de APIs alucinadas. Chega de métodos obsoletos. Basta adicionar "use context7" ao seu prompt. Suporta Next.js, React, Supabase, MongoDB e milhares de outros.
[https://github.com/upstash/context7]

### Task Master AI
O gerente de projetos da sua IA. Forneça um PRD (Documento de Requisitos de Produto) → tarefas estruturadas com dependências → o Claude executa uma por uma. Transforma sessões caóticas em um pipeline adequado. Funciona no Cursor, Claude Code, Windsurf.
[https://github.com/eyaltoledano/claude-task-master]
